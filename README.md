# Game Madness

Classmates pitch game ideas, vote through a March Madness-style bracket, and the game with the most total votes gets built.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fbb8832%2Fgame-madness&project-name=game-madness-vote&stores=%5B%7B%22type%22%3A%22blob%22%7D%5D)

## After deploying
1. Open `https://<your-site>.vercel.app/#host` and set a host passcode **before** sharing the link.
2. Share the plain link with your class. Anyone can pitch ideas and fill out a bracket, no account needed.
3. In Host controls, lock the pitches to open voting and set when voting ends (default: Friday 3 PM).

Votes are stored in a Vercel Blob store connected to the project.
